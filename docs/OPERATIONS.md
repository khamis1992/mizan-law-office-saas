# دليل تشغيل ميزان المكتب

## بدء الاستخدام

بعد النشر، ينشئ أول مستخدم حسابه من شاشة الدخول ثم ينشئ **مكتباً جديداً**. يصبح هذا المستخدم مدير المكتب تلقائياً، ويمكنه إرسال دعوات لأعضاء الفريق بدور محامٍ أو موظف. يفتح العضو رابط الدعوة، ينشئ حسابه أو يسجّل دخوله، ثم ينضم إلى المكتب والدور المقرر له.

## وحدات العمل

| الوحدة | الاستخدام العملي |
|---|---|
| القضايا | إنشاء الملف وربطه بالعميل وتعيين المحامي والحالة والمحكمة. |
| الجلسات | جدولة الجلسة وربطها بالقضية وتعيين وقت التذكير وتسجيل النتيجة بعد الانعقاد. |
| العملاء | إنشاء الملف القانوني، واستعراض القضايا، وإضافة سجل تواصل قابل للمراجعة. |
| المهام | توزيع المهام حسب الأولوية والموعد النهائي، وإغلاقها عند الإنجاز. |
| المستندات | رفع المذكرات والعقود والوكالات والأدلة وربطها بالعميل أو القضية في تخزين معزول. |
| التقارير | تحليل القضايا حسب الحالة والنوع مع نطاقات 30 و90 و365 يوماً. |
| مساعد المذكرات | إدخال الوقائع، فحص المصادر والمواد القانونية والسوابق المستوردة، ثم تحرير المسودة الناتجة. |

## قاعدة البيانات

تُحفظ ترحيلات Supabase ضمن `supabase/migrations/`. وتشمل إنشاء المخطط الأساسي والعزل عبر RLS، ثم تشديد صلاحيات الموظفين، والاستيراد الأولي للمصادر الدستورية والقوانين الأساسية والسوابق المنشورة. تُطبق الترحيلات من خلال بيئة إدارة Supabase المرتبطة بالمشروع، مع تجنب تغيير الجداول يدوياً كي لا ينفصل المخطط التشغيلي عن ملفات المشروع.

> **ضابط قانوني مهم:** المساعد القانوني أداة بحث وصياغة للمحامي. لا يجوز إيداع مسودة أو الاعتماد على مصدر أو سابقة قبل مراجعتها المهنية، والتحقق من سريان النص القانوني، ومراجعة الرابط الرسمي المرفق.

## قاعدة المعرفة القانونية

تعتمد المصادر المستوردة على بوابة الميزان القطرية. يتوفر سجل قابل للتدقيق في `docs/legal-source-register.md`، ويحفظ رابط المصدر الرسمي ورقم المرجع وتاريخ القرار. وتوجد أربع سوابق ابتدائية منشورة من محكمة التمييز لتشغيل ميزة البحث المماثل عبر مجالات الأحوال الشخصية والمدني والتجاري والعمل. يجب توسيع الفهرس بمصادر رسمية جديدة ومراجعتها قبل وضعها كـ `is_verified`.

## الاختبارات والبناء

تشغّل الأوامر التالية من جذر المشروع:

```bash
pnpm test
pnpm check
pnpm build
```

تغطي الاختبارات الحالية سلامة تسجيل الخروج، وتوفر أسرار التكامل، ومنع الاستشهادات القانونية غير الموجودة في السياق، وعقود RLS والسياسات المقيدة للأدوار، وتدفقات CRUD الأساسية للواجهة عبر اختبارات العقد. وتفصل سياسات RLS بيانات المكتب استناداً إلى `office_id` و`auth.uid()`؛ يجب إضافة اختبارات تكامل باستخدام حسابات منفصلة قبل أي توسيع للصلاحيات أو تغيير للسياسات.

جرى أيضاً تنفيذ فحص للسياسات على مشروع Supabase نفسه، إلى جانب اختبارات العقد وتحقق الواجهة المتجاوبة على سطح المكتب والجوال. يعتمد اختبار RLS التشغيلي متعدد الحسابات على حسابات QA مؤكدة؛ تحافظ بيئة المشروع الحالية على تأكيد البريد مفعلاً، ولذلك لا ينبغي تعطيله لمجرد الاختبار. لا تُغير هذا الإعداد دون قرار تشغيلي صريح من المكتب.

## تذكيرات الجلسات

يحفظ النظام `reminder_at` مع كل جلسة. عند حلول الوقت المحدد لجلسة ما تزال مجدولة، تظهر بطاقة تذكير داخل لوحة العمل تقود إلى شاشة الجلسات. هذا تنبيه داخل التطبيق، ولا يرسل رسائل بريدية أو رسائل نصية من تلقاء نفسه.
