# منصة SaaS المركزية — ميزان المكتب

## نطاق لوحة Super Admin

تعمل لوحة **Super Admin** كمساحة تشغيلية مستقلة عن لوحة كل مكتب. بعد تسجيل الدخول بحساب المنصة، لا تظهر بيانات القضايا أو العملاء؛ بل تُعرض المكاتب وحالة الخدمة والاشتراكات والخطط والمستخدمون والمؤشرات الإجمالية فقط. يستند الوصول إلى جدول `platform_admins` ودالة `is_platform_admin()` في Supabase.

| المجال | ما يستطيع Super Admin تنفيذه |
|---|---|
| المكاتب | عرض المكاتب، تفعيلها أو تعليقها، ومراجعة حالة الخدمة. |
| الاشتراكات | تعيين الخطة ومتابعة حالة التجربة أو الاشتراك المدفوع وتاريخ الفترة. |
| المستخدمون | عرض المستخدمين وأدوارهم ومكاتبهم، وتفعيل الحساب أو تعطيله. |
| الحوكمة | تسجيل تغييرات الخطة والخدمة والمستخدمين في `platform_audit_logs`. |
| المؤشرات | عدادات كلية ونمو المكاتب والمستخدمين والاشتراكات خلال 30 يوماً. |

## نموذج الاشتراك

تتضمن المنصة ثلاث خطط أولية: **تجربة مجانية** و**احترافي** و**مؤسسي**. عند إنشاء مكتب جديد، ينشئ المشغل `create_default_office_subscription` اشتراكاً تجريبياً تلقائياً لمدة 14 يوماً. تظل عمليات المكتب مسموحة في حالتي `trial` و`active`، بينما يمنع تعليق المكتب عمليات الكتابة عبر حراسة قاعدة البيانات نفسها، وليس الواجهة فقط.

> يتطلب ربط تحصيل مالي حقيقي اختيار بوابة دفع وتشغيلها لاحقاً. النسخة الحالية تدير الخطط وحالات الاشتراك والتفعيل التشغيلي ولا تنفذ تحصيل بطاقات أو فواتير خارجية.

## اختبار E2E المنفذ

نفذ التحقق التشغيلي الكامل بالتسلسل التالي: تسجيل دخول مدير مكتب QA مؤقت، إنشاء مكتب، التحقق من إنشاء اشتراك تجريبي تلقائياً، تسجيل دخول Super Admin، نقل الاشتراك إلى خطة احترافية، تعليق المكتب، التحقق من رفض كتابة بيانات العميل أثناء التعليق، إعادة التفعيل، ثم التحقق من نجاح الكتابة بعد التفعيل. حُذفت بيانات الاختبار وحساباته بعد نجاح الاختبار، وعادت المنصة إلى حالة لا تحتوي مكاتب تجريبية. تعذر تكرار خطوة إنشاء الحساب عبر واجهة Auth في الاختبار الأخير بسبب حد إرسال رسائل التأكيد المفعل في Supabase؛ يجب إعادة تنفيذ هذه الخطوة بعد انتهاء حد الإرسال دون خفض ضوابط تأكيد البريد.

## ضوابط الحساب الإداري

يُنشأ حساب Super Admin خارج عضوية أي مكتب، ولذلك لا يمكنه الدخول إلى تدفقات إنشاء المكتب أو دعوات الفريق. يجب حفظ بيانات الدخول في مدير أسرار مؤسسي وتغيير كلمة المرور المؤقتة فور أول تسجيل دخول. لا تحفظ بيانات الدخول داخل المستودع أو ملفات المشروع.
