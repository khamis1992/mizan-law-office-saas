# وحدات عمليات منصة SaaS

تضم لوحة Super Admin الآن وحدات مستقلة إضافية إلى جانب المكاتب والفواتير والتجديدات. تتوافر كل وحدة بمسار منفصل داخل `/platform/` مع شريط جانبي موحد وتجربة جوال متجاوبة.

| المسار | الوظيفة | الصلاحية |
|---|---|---|
| `/platform/audit` | البحث في سجل تدقيق المنصة وتصديره بصيغة CSV. | Super Admin فقط |
| `/platform/alerts` | تنبيهات التجارب القريبة من الانتهاء والمدفوعات المتأخرة والتجديدات. | Super Admin فقط |
| `/platform/plans` | إنشاء الخطط وتعديلها وتفعيلها أو إيقافها. | Super Admin فقط |
| `/platform/analytics` | مؤشرات الإيراد التشغيلي والتجديدات والإلغاءات. | Super Admin فقط |
| `/platform/support` | فتح تذاكر للمكاتب وإدارة الحالة والتعليقات الداخلية. | Super Admin فقط |
| `/platform/brand` | اسم المنصة والبيانات القانونية والتواصل وتذييل الفاتورة. | Super Admin فقط |
| `/platform/users` | تغيير دور المستخدم وتفعيل الحساب وإرسال رابط إعادة تعيين كلمة المرور. | Super Admin فقط |

## التنبيهات والتجديدات

ينشئ `sync_platform_notifications` تنبيهات عند قرب نهاية الفترة أو التأخر في السداد أو قرب نهاية التجربة. يمكن تشغيله يدوياً من مركز التنبيهات، كما أصبح جزءاً من معالج Heartbeat اليومي للتجديدات. لا يبدأ التشغيل اليومي قبل نشر النسخة وربط مهمة Heartbeat بالعنوان المنشور.

يتحقق المعالج من هوية `service_role` عند استدعائه من Heartbeat، فيما تتطلب الدعوات اليدوية صلاحية Super Admin. جرى اختبار حالة اشتراك متأخر (`past_due`) عملياً: أنشأ النظام تنبيهاً من فئة `renewal_failed` وبشدة `critical` وعنوان **فشل تجديد الاشتراك**، ثم حُذفت بيانات QA. يبقى التحقق المرئي من ظهوره داخل صفحة التنبيهات ضمن اختبار E2E التالي.

اكتمل أيضاً اختبار E2E مرئي بحساب Super Admin: ظهرت رسالة **فشل تجديد الاشتراك** وشدة `critical` داخل `/platform/alerts` على سطح المكتب والجوال، ولم يظهر تجاوز أفقي على الجوال. حُذفت بيانات الاختبار والتنبيه بعد التحقق.

## الدعم والحوكمة

يحفظ مركز الدعم التذاكر بحسب المكتب والحالة والأولوية، ويفصل التعليقات الداخلية للفريق عن الرسائل التي يمكن أن يراها المكتب. يسجل تغيير الخطط وحالة المكاتب والحسابات وإجراءات الفوترة في سجل تدقيق قابل للبحث والتصدير.

## التحليلات

تستخدم مؤشرات SaaS الفواتير المسجلة خلال آخر 30 يوماً وأحداث دورة الاشتراك لإظهار الإيراد التشغيلي والتجديدات والإلغاءات. لا تمثل هذه المؤشرات تحصيلاً بنكيًا معتمداً، لأن بوابة الدفع غير مفعلة بناءً على نطاق التنفيذ الحالي.
