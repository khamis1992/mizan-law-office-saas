# مراجعة لوحة Super Admin

**تاريخ المراجعة:** 14 أغسطس 2026  
**نطاق المراجعة:** إدارة المكاتب، المستخدمين، الخطط والاشتراكات، الفواتير، التجديدات، الصلاحيات، ومسارات المنصة.

## الخلاصة التنفيذية

اللوحة أصبحت قاعدة SaaS عملية وقابلة للاستخدام الإداري اليومي. تتوافر صفحات مستقلة للمؤشرات والمكاتب والفواتير والتجديدات والمستخدمين، وتُفرض صلاحيات المنصة في Supabase، كما نجح اختبار E2E في تسجيل الدخول والتنقل بين المسارات على سطح المكتب والجوال.

ومع ذلك، تحتاج اللوحة إلى تطويرات تشغيلية وتجارية قبل اعتبارها منصة SaaS مكتملة على نطاق تجاري: التحصيل الإلكتروني، سجل تدقيق قابل للبحث، إدارة كاملة لخطط المنتجات، تنبيهات تشغيلية، وتحليلات مالية أكثر عمقاً.

| المجال | الوضع الحالي | التقييم |
|---|---|---|
| المسارات والتنقل | صفحات مستقلة: Overview وOffices وInvoices وRecurring وUsers، مع شريط جانبي مشترك. | جاهز |
| إدارة المكاتب | تفعيل/تعليق المكتب وتغيير خطته وعرض حالته الأساسية. | جاهز تشغيلياً |
| إدارة المستخدمين | عرض المستخدمين وتفعيل/تعطيل الحسابات. | يحتاج توسيعاً |
| الاشتراكات | خطط وحالة تجربة/اشتراك وتجديدات شهرية أو سنوية. | جاهز أساسياً |
| الفواتير | مسودات واعتماد وتحصيل نقدي وحماية من الدفع الزائد وPDF عربي. | جاهز أساسياً |
| التجديد الدوري | مولد مسودات ومنع تكرار وواجهة إدارة؛ يلزم نشر النسخة لتشغيل Heartbeat اليومي. | جاهز تقنياً، غير مفعّل إنتاجياً |
| الأمان والعزل | RLS، Super Admin مستقل، وعزل بيانات المكاتب واختبارات عقود وتنفيذية. | جيد |
| الجوال | صفحات مستقلة وجداول بطاقات دون تجاوز أفقي في اختبار E2E. | جيد |

## ما يعمل الآن

يمكن لـ Super Admin مراجعة مؤشرات المنصة، إدارة المكاتب، تعليق أو تفعيل الخدمة، تغيير الخطة، مراجعة المستخدمين وتفعيلهم أو تعطيلهم، إصدار الفواتير الضريبية، تسجيل التحصيل النقدي، وتنزيل PDF. كما يمكنه ضبط الفوترة الدورية وتشغيلها يدوياً عند الحاجة. ترتبط الإجراءات الحساسة بسجل تدقيق في قاعدة البيانات.

## مراجعة تجربة المستخدم

| المسار | سطح المكتب | الجوال | الملاحظة |
|---|---|---|---|
| `/platform/overview` | بطاقات موجزة ومباشرة للمكاتب والخدمة والمستخدمين والاشتراكات. | بطاقات ضمن عمودين أو عمود واحد بحسب العرض. | يحتاج مؤشرات مالية فعلية لإثراء القرار الإداري. |
| `/platform/offices` | جدول مركزي مع تغيير الخطة وتعليق أو تفعيل الخدمة. | يتحول صف المكتب إلى بطاقة رأسية مع بقاء الإجراء والخطة. | مناسب للتشغيل اليومي، ويستفيد لاحقاً من البحث والفلاتر. |
| `/platform/invoices` | سير واضح للمسودة والاعتماد والتحصيل وPDF. | عناصر الفوترة قابلة للوصول في صفحة مستقلة. | يحتاج فلاتر الحالة والتاريخ وتنزيل كشف جماعي. |
| `/platform/recurring` | صفحة مستقلة لدورات التجديد والتشغيل اليدوي. | التنقل متاح من شريط علوي قابل للتمرير. | التفعيل الإنتاجي ينتظر النشر ومهمة Heartbeat. |
| `/platform/users` | جدول لإدارة التفعيل والتعطيل وربط المكتب. | يتحول الجدول إلى بطاقات لتجنب التمرير الأفقي. | يحتاج تعديل الدور وإعادة إرسال الدعوات. |

تم تنفيذ E2E بحساب Super Admin للمسارات الخمسة وعلى مقاسي 1440×1000 و390×844. تحقق الاختبار من العنوان الصحيح لكل صفحة، ووجود التنقل، وعدم وجود تجاوز أفقي على الجوال. تحفظ نتائج هذا الاختبار في `docs/E2E_PLATFORM_ADMIN.md`.

## أولويات التطوير

| الأولوية | التطوير المقترح | الأثر | السبب |
|---|---|---|---|
| P0 | نشر النسخة وتفعيل مهمة Heartbeat اليومية | عالٍ | يجعل التجديدات الدورية تعمل تلقائياً بدلاً من الوضع اليدوي. |
| P0 | ربط بوابة دفع وإشعارات دفع ويب هوك | عالٍ | التحصيل الحالي نقدي/يدوي فقط ولا يناسب SaaS تجارياً. |
| P1 | صفحة سجل التدقيق مع بحث وفلاتر وتصدير | عالٍ | السجل موجود لكن لا توجد واجهة تشغلية لمراجعته. |
| P1 | مركز تنبيهات للمدفوعات المتأخرة وفشل التجديد وانتهاء التجربة | عالٍ | يقلل تدخل مدير المنصة اليدوي. |
| P1 | إدارة موسعة للمستخدمين | متوسط | تشمل تغيير الدور، إرسال رابط إعادة تعيين، وإعادة إرسال دعوات. |
| P1 | إدارة الخطط من الواجهة | متوسط | الخطط معروضة ويمكن إسنادها، لكنها لا تُنشأ أو تُعدل من الواجهة. |
| P2 | تحليلات SaaS مالية | متوسط | إضافة MRR وARR ونسبة التحويل والانحسار والإيراد حسب الخطة. |
| P2 | مركز دعم | متوسط | تذاكر الدعم، سجل تواصل المكتب، وتعليقات داخلية للفريق. |
| P2 | إعدادات العلامة التجارية | منخفض | شعار، نطاقات بريدية، قوالب فواتير، ورسائل مخصصة لكل منصة. |

## توصية التنفيذ

المرحلة التالية الأنسب هي **P0**: نشر المنصة، تفعيل Heartbeat، ثم اختيار بوابة دفع وربط دورة الدفع بالفاتورة والاشتراك. بعد ذلك، يفضل تنفيذ صفحة سجل التدقيق ومركز التنبيهات قبل إضافة أي لوحات تحليلية متقدمة، لأنهما يحسنان قدرة تشغيل المنصة ومتابعة الحالات الاستثنائية.
