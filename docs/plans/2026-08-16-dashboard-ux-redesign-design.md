# تصميم لوحة تحكم «غرفة القرار» — ميزان المكتب (2026-08-16)

من أ خراج: عصف ذهني (3 مفاهيم) + تفكير متسلسل (10 خطوات) — التفاصيل في `notes.md`.

## الفكرة المحورية
اللوحة ليست «عرض مؤشرات» بل **غرفة قرار يومية**: أول ما تقع عليه العين ما ينتظر قرارك (اعتماد عقد / تنفيذ وكيل)، ثم مسطرة يومك الزمنية بإجراء سطري لكل بند، وبجانبها شريط نبض رفيع للمكتب وذكائه القانوني. البنية: عمودان فقط، صفوف داخل لوحات — لا بطاقات حرة، ولا لون واحد جديد.

## التشريح

### الترويسة (لوحة بيضاء واحدة)
تاريخ عربي كبير + تحية زمنية + سطر ملخص آلي (قرارات معلقة/جلسات اليوم/مهام مستحقة) + شريط التقاط سريع: رقائق (عميل/جلسة/مهمة/مستند) + زر داكن «بحث قانوني». للمحامي/المدير فقط.

### العمود الرئيسي — «اليوم والقرار»
1. **بانتظار قرارك** (يظهر فقط عند وجود عناصر):
   - عقد بحالة «مراجعة محامٍ»: العنوان + النسخة + زرا «اعتماد داخلي» (in_review→approved) و«إعادة لمسودة» (in_review→draft) بتأكيد.
   - تشغيل وكيل معلق: نوعه + وصف الإجراء المعلق + زرا «موافقة وتنفيذ» و«رفض» بتأكيد.
   - بعد كل إجراء: toast + onRefresh (إعادة جلب Home).
2. **مسطرة اليوم**: دمج جلسات اليوم+غد (scheduled) ومهام مستحقة اليوم+غد، مرتبة بالوقت؛ كل صف: شريحة وقت (HH:mm)، أيقونة نوع (جلسة/مهمة)، عنوان + سياق (قضية/محكمة)، إجراء سطري واحد (تسجيل نتيجة للمحامي / إغلاق للمهمة المسندة). خط عمودي متصل بنقاط يمنى اللوحة (لغة «الخط الزمني»).
3. **هذا الأسبوع**: عندما تخلو المسطرة تتوسع تلقائياً لتعرض جلسات الأسبوع مجمعة باليوم (شريحة يوم + صفوف مختصرة)، وإلا تظهر كملخص مضغوط بأعلى 3.

### الشريط الجانبي — «نبض المكتب»
- **مؤشرات 2×2** بلا إطارات: قضايا نشطة / جلسات الأسبوع / مهام متأخرة (من مفتوحة) / الفريق؛ كل مؤشر قابل للنقر لصفحته مع شريط نسبة رفيع تحت الرقم (نفس لون الشريحة).
- **عبء الفريق**: أعلى 3 محامين بأشرطة نسبية (قضايا+مهام).
- **آخر النشاطات**: 3 صفوف (متابعات عملاء + نتائج جلسات) مع رابط للتقارير.
- **لوح الذكاء القانوني** (الداكن الوحيد، رفيع): حلقة SVG لحصة الاستخدام (used/cap بلون ذهبي #e8c377 على مسار #edf4f1/أبيض-شفاف) + «المتبقي N من M» + ثلاثة أزرار أيقونية (بحث/عقود/وكلاء) + سطر تحفظ. للمحامي/المدير؛ الموظف يرى نسخة بلا حلقة.

### خط البداية (مكتب جديد)
قائمة تحقق 4 خطوات بعلامات إنجاز حقيقية — تبقى كما هي فوق العمودين.

## تدفق البيانات
- Home يجلب إضافياً: `contract_documents` (status in_review)، `agent_runs` (status awaiting_approval, آخر 8) — RLS تسمح للقراءة لكل المكتب.
- `aiUsage.quota` تتحول من mutation إلى **query** (قراءة نقية) ليستخدمها اللوحة بـ useQuery.
- الإجراءات: `contractStudio.transition` و`agents.approve` (موجودتان) مع confirm() ثم onRefresh.

## الأدوار والحدود
- الموظف: الترويسة بلا شريط التقاط؛ بلا «بانتظار قرارك»؛ إغلاق المهمة لمهامه فقط؛ بلا حلقة الحصة.
- الأمان: كل زر مؤثر خلف تأكيد صريح، والإجراء يمر بالخادم (صلاحيات + RLS) لا بالواجهة فقط.

## معايير القبول

- لا بطاقة حرة واحدة خارج اللوحات المعرّفة؛ لوح داكن واحد فقط؛ صفر ألوان جديدة.
