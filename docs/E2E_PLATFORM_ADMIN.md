# تحقق E2E للوحة Super Admin

تم تسجيل الدخول بحساب Super Admin ثم فتح المسارات المستقلة التالية: `overview` و`offices` و`invoices` و`recurring` و`users`. تأكد الاختبار من ظهور العنوان الخاص بكل صفحة وبقاء الشريط الجانبي على سطح المكتب، ومن ظهور التنقل الأفقي المتجاوب وعدم وجود تجاوز عرض أفقي على مقاس 390 بكسل.

في الفحص المرئي لمسار **المكاتب**، ظهر جدول المكاتب على سطح المكتب بكامل الأعمدة وعمليات التعليق وتغيير الخطة. وعلى الجوال تحول صف المكتب إلى بطاقة عمودية قابلة للقراءة تعرض الاسم والخطة والحالة والمستخدمين والاستحقاق والإجراء، ولم يظهر قص خارج العرض.
